News Portal is a front-end web project created to simulate a modern online news platform.
The goal of the project is to demonstrate layout organization, responsive design, and clean UI structure commonly used in digital newspapers and media websites.

This project is useful for practicing:

  HTML layout structuring

  CSS styling and responsive design

  Front-end project organization

  GitHub Pages deployment


🚀 Features


  Featured news section
  
  Organized news cards
  
  Category-based layout
  
  Responsive design
  
  Clean and modern UI
  
  Fast static website


🛠️ Technologies Used


  HTML5
  
  CSS3
  
  JavaScript
  
  Git & GitHub
  
  GitHub Pages for deployment
